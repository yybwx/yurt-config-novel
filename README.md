# Yurt 小说源

供 Yurt 小说板块使用的独立源适配仓库，提供公开网站的搜索、详情、目录、正文与插图解析规则。

源清单地址：

```
https://raw.githubusercontent.com/yybwx/yurt-config-novel/main/index.json
```

Git 仓库首页地址不能直接当作源清单使用。源管理需要的是上述 JSON 文件内容，单个源导入需要对应 JS 的 Raw 文件地址。

## 源

| 源 | 适配文件 | 范围 |
| --- | --- | --- |
| 神凑轻小说 | shencou.js | 搜索、详情、分卷目录、正文/插图、发现、分类 |
| 拷贝轻小说 | copy_novel.js | 搜索、详情、按卷目录/阅读/下载、正文与插图、热门/更新/新书、分类 |

哔哩轻小说的直接请求目前存在访问限制，尚未列入可安装源。目录可以打开并不代表正文完整可用。

发布清单更新后，在 Yurt 的“小说源”中刷新仓库，安装“拷贝轻小说”。两个源有独立身份，安装拷贝不会替换神凑或改变漫画源。已安装源不会因清单增加条目而被自动更换。单源 Raw 地址为 `https://raw.githubusercontent.com/yybwx/yurt-config-novel/main/copy_novel.js`，最低客户端版本为 1.6.3。

拷贝第一版按卷列目录、阅读和下载，使用站点固定卷 ID；卷内保留小章节标题和插图，暂不提供卷内小章节的独立目录跳转。卷目录请求不预取 TXT。读取时按服务器 `txt_encoding` 和原始行号解析 UTF-8/GBK，保留空行位置与图片顺序，按页返回原生阅读块。API 请求不读取漫画登录数据；正文和图片请求不复制 API 身份头，沿用客户端正常浏览器 UA/Cookie 处理。

脚本只在内存复用最近一卷，缓存 5 分钟，同卷并发请求共享读取；最多两个卷读取在途。正文上限 4 MiB、50,000 行和 40,000 个块，超限明确报错，不标完整。正文截断、缺插图地址或未知内容类型保留可读内容和未完整状态，用户可重试或结束保留；访问受锁定限制的卷不会取得正文。当前只支持可匿名读取的内容，没有小说账户登录/VIP 解锁功能。

2026-10-09 拷贝适配脚本通过 Yurt QuickJS 的合成搜索/分页/编码/并发/缺失内容测试，并验证坏图后后续卷继续、本地阅读和 EPUB 导出。真实抽查两本书的首卷/末卷共四卷，卷数分别为 11/34，正文有 4,510/4,870/4,413/11,665 个块；插图数量分别为 20/18/20/0，并验证有图卷的抽样图片。首次联网检查有一次连接超时，随后原生链路重测成功。Android 安装源和实际浏览器验证仍需真机验收，样本通过不保证全站或未来始终可用。

2026-10-08 已在 Yurt 的 QuickJS 和原生网络链路中抽查神凑搜索、详情、三本书的目录、短章及长章。分卷样本的完整目录包含 234 章、11 个卷标签，插图章按顺序解析出 21 张图片。网站内容和分页可能随时变化，以上为当时样本的验证结果。

部分插图请求会遇到网站的浏览器验证。Yurt 会保存已取得的正文，显示验证/重试入口，缺插图的章节不会被标为完整下载。Android 浏览器验证后的图片读取仍需真机验证。

Cloudflare 403 可能是需要用户验证，也可能是直接拒绝访问。有验证挑战时可在 App 浏览器中正常操作，保存本站 Cookie/UA 后重试；“Sorry, you have been blocked”页面没有证明存在可完成的验证。哔哩在当前原生请求中返回此类阻止页，尚未验证浏览器处理后可读取完整正文，因此没有发布哔哩脚本。

Yurt 下载保存为 App 内的离线正文和插图。支持 EPUB 导出的客户端会在下载完成或结束保留时生成内部 EPUB，并提供手动导出入口，可选择保存到手机目录；缺图不妨碍导出已保存内容。较早的客户端需要升级到包含该功能的版本。当前未提供 TXT 导出或外部 EPUB 导入。

本仓库保存适配规则，不保存小说全文、用户账户、Cookie 或下载文件。网站内容及插图属于对应作者与权利人，使用应遵守网站规则。

编写新源参见 [小说源接口](novel-source-api.md)。更新 JS 时同步清单版本；发布前使用 Yurt 的小说源测试验证分页、编码、错误页及本地阅读。

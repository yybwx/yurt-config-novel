# Yurt 小说源

供 Yurt 小说板块使用的独立源适配仓库，提供公开网站的搜索、详情、目录、正文与插图解析规则。

## 安装与更新

在 Yurt 的“小说源与设置”中使用以下源清单地址：

```text
https://raw.githubusercontent.com/yybwx/yurt-config-novel/main/index.json
```

读取仓库清单后选择安装；已安装源通过“更新源”获取新版本。Git 仓库首页不能代替 JSON 清单，单源导入需要对应 JS 的 Raw 地址。各源独立安装，新增清单条目不会自动替换已安装源，也不影响漫画源。

### 拷贝轻小说

按卷列目录、阅读和下载，卷内保留小章节标题与插图，暂不支持卷内小章节的独立目录跳转。仅支持可匿名读取的内容，不提供小说账号登录或 VIP 解锁。最低客户端版本为 1.6.3。

拷贝源 1.1.0 支持免登录查看评论与楼内回复，包括分页、刷新和失败重试。需使用包含小说评论界面的 Yurt 客户端并更新源，随后在详情页点击“评论”。评论不进入下载或 EPUB，不提供发表评论或点赞。

单源地址：

```text
https://raw.githubusercontent.com/yybwx/yurt-config-novel/main/copy_novel.js
```

### 52书库

52书库(`shuku52`)是收录 GL 百合、耽美、言情等完结中文网络文学的阅读站，可匿名访问。站点按整本“第 N 页”分页、没有章节目录，因此目录只列一个“全书正文(共 N 页)”单元，阅读和下载时按续页连续翻页，章节名保留在正文中。单源 Raw 地址为 `https://raw.githubusercontent.com/yybwx/yurt-config-novel/main/shuku52.js`，最低客户端版本 1.6.3。书籍 ID 使用站点自身路径，兼容新旧两种地址模板；搜索关键词用与浏览器一致的大写百分号编码。该站没有插图和账户体系，正文以纯文字为主。

### 69书楼

69书楼(`shuku69`)是中文网络小说镜像站，按章列目录、阅读和下载，支持搜索、书籍详情、推荐/最新/更新栏目和分类浏览，可匿名访问。站点搜索与作者页共用一个模糊匹配入口，结果会混入站内推荐且只有一页。正文以 base64 段落下发，源解码为纯文字段落，没有插图。单源 Raw 地址为 `https://raw.githubusercontent.com/yybwx/yurt-config-novel/main/shuku69.js`，最低客户端版本 1.6.3。该站部分书籍存在源站缺失的章节，目录如实反映站点数据。

## 阅读与下载

正文或插图缺失时，已取得的可读内容会保留，可选择重试或结束保留；缺失章节不会被标为完整下载。浏览器验证提示可在 App 中打开验证，完成后重试。普通拒绝访问页面不一定提供可完成的验证。

下载保存在 App 私有目录，可通过“导出 EPUB”保存到选择的手机目录；缺图不妨碍导出已保存内容。当前不提供 TXT 导出或外部 EPUB 导入。网站内容、接口和访问规则可能变化，实际可用范围以站点响应为准。哔哩轻小说尚未列入可安装源。

本仓库保存适配规则，不保存小说全文、用户账户、Cookie 或下载文件。网站内容与插图属于对应作者与权利人，使用应遵守网站规则。

## 编写与维护

编写新源参见 [小说源接口](novel-source-api.md)。修改 JS 时同步 `index.json` 版本，发布前验证分页、编码、错误页与本地阅读。
